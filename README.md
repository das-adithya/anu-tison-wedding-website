# Anu Paily & Tison Titus — Maduram Veppu Invitation

A responsive static wedding invitation website.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome or Edge. Keep the `assets` folder beside it.

## Before publishing
1. Confirm the family name spellings and the event location/walking route.
2. Ensure the couple has consented to public display of the photo and RSVP number.
3. The couple photo is in `assets/anu-tison-couple.png`. `assets/invitation-design-reference.png` is a visual reference and is not used as the live hero image.
4. The Google Calendar link creates an all-day event to avoid assuming an end time.

## Free hosting with GitHub and Vercel
1. Create a GitHub repository, for example `anu-tison-maduram-veppu`.
2. Upload `index.html` and the entire `assets` folder to the repository root.
3. In Vercel, choose **Add New → Project**, import the repository, and deploy with the default static settings.
4. Test the deployed link on a phone before sharing.

This is a static website; no build command or paid database is required. Review current hosting plan terms before deploying.
